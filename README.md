# python-simple-app

A simple Python web application built with [Flask](https://flask.palletsprojects.com/).

## What It Does

When you visit the root URL (`/`), the app responds with:

```
Good day folks!
```

## Prerequisites

- Python 3
- pip

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Bashayr29/python-simple-app.git
   cd python-simple-app
   ```

2. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Running the App

```bash
python app.py
```

The app will start in debug mode and be available at [http://127.0.0.1:5000](http://127.0.0.1:5000).
